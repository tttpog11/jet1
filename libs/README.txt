Put RimuLib's Fabric jar here, as you downloaded it (for example rimulib-1.3.0-fabric.jar).

It holds one build per Minecraft version inside; the build script takes the 1.21.11 one out and compiles against it.
It is never copied into the addon's jar. Keep exactly one rimulib*.jar in this folder.

Get it from https://www.curseforge.com/minecraft/mc-mods/rimulib (the file for Fabric).
